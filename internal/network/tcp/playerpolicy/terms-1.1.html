What happens to your progress

Live appears in server select as Vanilla Test - Wipes. A test wipe can reset characters and progress there. Heirloom appears as Sandbox Test - No Wipes. Characters carry over under its no-wipe policy. On either server, an outage, a bug or recovery from a backup can cause downtime or the loss of recent progress. We may have to pause or close a server if we lose hosting, face a rights claim or can no longer run it. Closing a server can end access to characters there. Server guide
